# Security Policy

## Supported Versions

The latest version of this project on the `main` branch is the supported version. Older versions are not actively maintained.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not create a public GitHub issue containing sensitive details.

Instead, report the vulnerability privately using GitHub's **Report a vulnerability** feature under the repository's Security tab, if private vulnerability reporting is enabled.

If private reporting is unavailable, contact the repository maintainer through a private communication channel.

When reporting a vulnerability, include:

- A description of the security issue.
- Steps to reproduce the problem.
- The affected files or functions.
- Any recommendations for fixing the issue.

## Security Updates

The maintainer will review reported vulnerabilities and work on appropriate fixes.

Security fixes will be tested before being merged into the `main` branch. Updates will be documented in GitHub commits or releases when appropriate.

## Security Best Practices

Contributors should never commit passwords, API keys, access tokens, or other secrets to this repository. Dependencies and source code should be checked regularly for security issues.
